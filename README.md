# MY STUFF — MVP

Первая локальная версия личного инвентаря.

## Уже работает
- Добавление, редактирование и удаление предметов.
- Фотографии (до 4 МБ на изображение).
- Название, описание, количество и теги.
- Учёт группового количества или индивидуальных экземпляров.
- Места хранения, статусы, поиск и фильтры.
- Светлая и тёмная темы.
- Локальная база IndexedDB.
- Экспорт и импорт JSON-резервной копии.
- PWA-основа для установки на iPhone и Windows.

## Запуск
Для теста откройте `index.html` в современном браузере. Для PWA и Service Worker нужен HTTPS или localhost.

Удобный локальный запуск из папки проекта:
```bash
python -m http.server 8000
```
Затем откройте `http://localhost:8000`.

Чтобы открыть приложение на iPhone, разместите файлы на HTTPS-хостинге и откройте адрес в Safari → Поделиться → На экран «Домой».

## Важно
Это MVP хранит данные локально в браузере. Автоматическая облачная синхронизация, аккаунт по почте и отдельные места/статусы для каждого экземпляра ещё не подключены. До подключения облака регулярно используйте экспорт резервной копии. Очистка данных браузера может удалить локальный каталог.
